
# Multimodal Attendance & Engagement Agent

## Project Overview
This project aims to build an attendance and engagement monitoring system using computer vision, audio analysis, and AI-based insights.

## Technologies Used
- Python
- Streamlit
- OpenCV
- MediaPipe
- Librosa
- NumPy
- Pandas

## Development Environment
- Visual Studio Code
- Python 3.14
- Local execution
- Webcam or video input
- Optional microphone or audio file input

## Planned Features
- Attendance record management
- Visual analysis using computer vision
- Audio feature analysis
- Engagement analytics
- Dashboard and recommendations

## Setup Instructions
1. Install Python.
2. Create and activate a virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Run the application using Streamlit.

## Project Status
Environment setup completed. Application modules are under development.
